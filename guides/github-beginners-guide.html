GitHub Basics

A quick, beginner-friendly introduction. Click a card to learn.

A repository, or repo, is a project folder stored on GitHub. It contains your code, files, and project history.

Think of it as an online home for your project.

A commit is a saved snapshot of your changes. Add a short message so you know what changed.

git commit -m "Add homepage"

A branch lets you work on a feature without changing the main project immediately.

git switch -c new-feature

A pull request asks your team to review your branch and merge it into the main branch.

It is a place for discussion, feedback, and approval.

Clone downloads a repository to your computer. Push sends your local commits back to GitHub.

git clone <repository-url> git push

A README explains what your project does and how someone can use it.

Start with the project name, purpose, setup steps, and examples.

Simple workflow: create a branch, make changes, commit them, push the branch, and open a pull request.
